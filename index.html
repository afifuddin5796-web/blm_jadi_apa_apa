Irigasi

Model aplikasi untuk petugas irigasi: peta daerah irigasi, debit air tiap bendung, dan laporan tanaman. Semua angka di sini masih data contoh. Satuan: luas dalam hektar (ha), debit dalam liter per detik (lt/dt), panjang jaringan dalam km dan m.

LPR dan FPR petak tersier

LPR (ha palawija) = luas tanam × koefisien tanaman. Kebutuhan debit di pintu tersier = FPR standar × LPR. FPR realisasi = debit terukur ÷ LPR. Faktor K = FPR realisasi ÷ FPR standar; K di bawah 1 berarti air kurang. Koefisien, FPR standar, dan efisiensi di bawah adalah nilai awal: sesuaikan dengan ketetapan Dinas atau UPTD. Luas dan debit pada tabel bisa diubah langsung.

Info dasar

Isi sekali saja. Info ini tampil di bagian atas aplikasi, dipakai sebagai nama daerah irigasi saat impor, dan ikut tersimpan di cadangan JSON.

Peta dari KMZ atau KML

Unggah file dari Google Earth. Aplikasi membaca folder dan penanda di dalamnya, lalu Anda menentukan setiap folder menjadi apa (daerah irigasi, petak, saluran, bendung, atau bangunan). Impor ini mengganti peta dan data jaringan yang ada, jadi unduh cadangan dulu bila perlu. Untuk menggabungkan beberapa file, satukan dulu di Google Earth.

Masukkan data asli

Peta: simpan hasil Google Earth (KML) menjadi GeoJSON lewat QGIS. Poligon dibaca sebagai daerah irigasi, garis sebagai saluran, titik sebagai bendung. Nama diambil dari kolom nama atau name.

Kolom CSV tanaman berurutan: di, musim, padi, jagung, palawija (luas dalam hektare, baris pertama judul).

Cadangan data (JSON)

Cadangan berisi semua data: bendung dan debit, peta, laporan tanaman, petak tersier, bangunan dan saluran, pengaturan koefisien, serta catatan. Simpan file ini secara berkala, dan gunakan untuk memindahkan data ke perangkat lain atau ke aplikasi lain.

KML berisi bendung, bangunan, saluran, dan petak per daerah irigasi lengkap dengan keterangannya. Buka di Google Earth (Pro atau web) atau impor ke Google My Maps.

Impor JSON atau Excel

Pilih file JSON dari aplikasi lain, tentukan jenis datanya, lalu cocokkan nama kolomnya. Cadangan dari aplikasi Irigasi ini sendiri dipulihkan lewat pilihan di atas.

Wilayah diambil dari nama Juru Pengairan. Petak yang sudah ada (nama cocok) diperbarui, yang belum ada ditambahkan. Debit bendung dan petak diambil dari formulir 06. Impor ini mengganti data contoh bila masih ada.

Saluran digambar di peta sesuai koordinat aslinya. Wilayah belum terbagi karena file tidak memuat pembagian wilayah. Setelah impor, unduh cadangan JSON agar data tidak hilang saat halaman ditutup.
